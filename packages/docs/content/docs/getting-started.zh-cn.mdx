**Education Researcher** 基于开源 BrainPilot，面向教育学研究。新会话默认选择**教育研究**；需要原有脑科学能力时，可以在新会话中主动选择**脑科学研究**。研究方向影响提示词和可调用的内置资源，不会删除底层模型已有的知识。

教育版须从[本仓库源码](https://github.com/Kirihara-Ryouji/Education-Researcher)运行。上游发布的 `@brainpilot/app@0.2.3`、官方沙箱镜像和 `brainpilot.chat` 托管服务不包含本分支的教育研究改动。

> **研究数据：**先用虚构或去标识化的示例熟悉流程。真实学生资料须遵守机构的伦理、授权、知情同意和数据管理要求；不要把可识别资料或密钥直接发送给外部模型。

## 1. 从源码启动

准备 **Node.js 22.13.0 或更新版本**及 npm。克隆仓库后进入应用根目录：

```bash
git clone https://github.com/Kirihara-Ryouji/Education-Researcher.git
cd Education-Researcher
npm ci
npm run build
npm run bp -- up
```

在浏览器打开终端显示的本地地址。前台进程可按 `Ctrl-C` 停止。通过 `npm run` 使用 CLI 时，`--` 分隔符必须保留。安装、数据目录与更新说明见[安装与更新](./installation)。

若只想检查界面和流程，可使用无密钥 mock 模式；其回复不能用于评价教育研究能力：

```bash title="macOS / Linux"
BP_MOCK=1 npm run bp -- up
```

```powershell title="PowerShell"
$env:BP_MOCK = '1'
npm run bp -- up
```

## 2. 配置模型服务商

真实任务需要你自己的模型服务商。在 **Settings → Providers（服务商）→ Add Provider（添加服务商）** 填写服务商名称、API 根地址、端点协议、密钥及准确的模型 ID。协议应与端点实际格式一致，不能仅凭模型名称判断。

保存后点 **Use（使用）** 设为新会话默认服务商，再点 **Test（测试）** 发起一次最小真实请求。测试可能消耗少量额度。密钥只填在本机设置中，不要放进聊天、截图或仓库。各协议与配置路径见[模型服务商](./providers)。

## 3. 完成第一个教育研究任务

点**新建会话**，确认“研究方向”为**教育研究（默认）**，并确认模型。可以从容易人工核验的小任务开始：

> 请为“初中数学课中的形成性反馈是否改善学生的问题解决表现”拟一页研究方案。列出研究问题、可选设计、干预与结果测量、可能的混杂因素、伦理注意点及待查证的证据。不要编造论文、效应量或已有数据。

写清研究情境、方法约束、预期产物和需要人工审阅的决定。智能体提供的是辅助分析；引用、测量效度、统计假设与教育解释仍需研究者逐项核对。想保留更完整的来源、方案及版本记录，可使用[研究工作区](./research-workspace)。

## 4. 从研究工作区交接方案

在**研究项目**中新建项目与研究，填写研究问题、学段、课程、机构与待确定事项。登记来源及证据，核对原始材料，再保存并**接受当前研究方案**。

随后在**执行关联 → 交给教育研究智能体**创建新教育会话。工作台只把已接受的当前方案和符合条件、带引文的出版物摘录写入**尚未发送的草稿**。原始文件、表格行和参与者记录不会自动附上；自由文本中仍可能含个人信息，所以发送前必须检查草稿。交接不代表模型独立核实了来源。

## 5. 核对结果

在**对话、文件、智能体和轨迹**中查看请求、工具调用、生成产物及结论依据。至少检查：

- 引用的论文是否真实存在，原文是否支持相应论断；
- 样本、变量、测量、缺失值与排除规则是否写清；
- 数值是否能从保存的文件与代码复算；
- 因果解释是否受到设计支持，哪些结论仍需人工判断。

原有**插件 → 数据集**目录以脑科学数据为主，是可选资源；教育会话不会自动加载这些数据。上传教育论文全文并索引的本地知识库与教育会话的默认资源边界见[技能与知识库](./skills-knowledge-base)。

## 常见问题

| 现象 | 优先检查 |
| --- | --- |
| 启动失败 | Node.js 是否至少为 22.13.0、是否位于 `Education-Researcher` 仓库根目录、是否已运行 `npm ci` 与 `npm run build` |
| 端口被占用 | 运行 `npm run bp -- up --port 9010` |
| 服务商返回 401/403/404 | 核对密钥、权限、API 根地址、协议和模型 ID |
| mock 回复缺乏研究能力 | mock 只验证界面；配置并测试真实服务商 |
| 旧会话仍显示脑科学 | 无领域标记的历史会话按原设置保留；请新建教育会话 |
| 研究工作台无法交接 | 先保存并接受**当前**方案，并检查模型运行环境 |
| MCP 工具不可见 | 在服务器设置中选择“教育研究”，再新建会话 |

更多诊断见[故障排查](./troubleshooting)，教育领域的人工评价项目见[验收用例](https://github.com/Kirihara-Ryouji/Education-Researcher/blob/main/EDUCATION-EVALUATION.md)。
