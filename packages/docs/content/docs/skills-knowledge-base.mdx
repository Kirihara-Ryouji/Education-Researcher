Education Researcher includes six education research methods skills: **evidence review, study design, measurement, qualitative inquiry, learning analytics and privacy, and education AI evaluation**. They are methodology documents available when relevant, not a newly trained model or a full-text paper corpus. The original BrainPilot neuroscience skills remain for sessions explicitly set to neuroscience; education sessions discover education and allowed general-purpose skills by default.

The education skill directory's [authoritative source index](https://github.com/Kirihara-Ryouji/Education-Researcher/blob/main/packages/skills/skills/22_Education/AUTHORITATIVE_SOURCES.md) links to methods, reporting, and ethics entry points. It is an **index of source links**, not a downloaded education full-text collection. Check the original text before citing any specific study result.

## Built-in Skills

Skills live in the repository under:

```text
packages/skills/skills/
```

At runtime, they are materialized into the data directory:

```text
brainpilot/bp_template/skills/
```

The runtime does not overwrite existing user-edited skills when scaffolding the data directory.

## What a Skill Contains

Each skill has a `SKILL.md` file with required frontmatter:

```yaml
---
name: "skill-name"
description: "A keyword-rich summary used for matching."
domain: "education-research"
version: "1.0.0"
---
```

The description helps the agent decide when the skill is relevant. Keep it clear, specific, and searchable.

## Add a Skill

To contribute a built-in skill:

1. Choose an existing category under `packages/skills/skills/`, or add a new category.
2. Create `<category>/<skill-name>/SKILL.md`.
3. Put long reference tables, examples, or raw material under `references/`.
4. Run the skills package build before opening a PR:

```bash
npm run build -w @brainpilot/skills
```

## Extend the education skills

Use the [six built-in education skills](https://github.com/Kirihara-Ryouji/Education-Researcher/tree/main/packages/skills/skills/22_Education) as a pattern for methods you have checked. Record the source, education level, measurement assumptions, ethics limits, and version date.

- **`paper-to-skill`** can draft a method skill from a paper, PDF, or text; the researcher must verify source text, parameters, citations, and reuse rights.
- **`repo-to-skill`** can structure methods from a trusted code repository; check that the code and documentation versions match.
- Put user-edited skills under `<data-dir>/bp_template/skills/<category>/<skill-name>/SKILL.md`, then verify visibility in a new session. Education resource filtering does not automatically admit arbitrary neuroscience skills.

The upstream [`awesome_cognitive_and_neuroscience_skills`](https://github.com/NeuroAIHub/awesome_cognitive_and_neuroscience_skills) and [`nature-skills`](https://github.com/Yuan1z0825/nature-skills) projects remain optional original-project resources; they are not an education research corpus and are not automatically used by education sessions.

## Original local paper index

The following upload and indexing workflow belongs to the original BrainPilot local knowledge base. **Education sessions do not call its local neuroscience knowledge-search tools by default.** For education research, use [Research workspace](./research-workspace) to register, check, and cite publications. To search your own education corpus automatically, connect a reviewed retrieval service assigned to the education domain.

Open **Settings → Knowledge Base**, or **Plugins → Knowledge Base → My knowledge base / Add papers** in a local installation.

1. Select **Choose PDFs** and upload one or more papers. Each PDF must be nonempty, valid, and no larger than 256 MB. A duplicate filename is rejected; rename it if you intend to keep both versions.
2. Select **Start preparing** to install the local search environment and embedding/reranker models. The UI estimates about 2.5 GB of downloads and at least 3 GB of free space; duration depends on the network and machine.
3. Configure OCR and metadata extraction under **Advanced and troubleshooting**, then start indexing. These stages can send document content to the selected external services; embedding and reranking run locally.
4. Wait until the knowledge base reports it is searchable. Add more PDFs and run indexing again when needed; upload completion alone does not mean a paper has been indexed.

The advanced area shows setup/build stages and logs. Scroll up to read earlier output without following new lines, then select **Jump to latest logs** to resume following; scrolling the log does not cancel the build. A failed step can be retried after correcting its configuration.

npm installations materialize the bundled pipeline under `~/.brainpilot/KnowledgeBase/`. `BP_KB_ROOT` overrides that location. For source and container deployments, consult the detected path in the advanced panel. Back up the actual knowledge-base root as well as the BrainPilot data directory if they are separate. See [Docker deployment](./docker) for sharing the root between backend and runtime.

The local management UI is disabled in hosted Cloud. Availability of preconfigured hosted retrieval is controlled by the service.

## Connect education literature retrieval

The open-source package does not include a ready-to-search, full-text education paper collection. You can connect your own education literature retrieval through MCP and assign the server to **Education research**:

- an institution-authorized education publication or policy collection
- a paper search service that provides stable source locators and access dates
- a filesystem or database tool restricted to authorized folders
- an internal literature review API

Check returned summaries, excerpts, and citations against original texts. [MCP Tools](./mcp) explains domain assignment and data-access boundaries.

## Verification Reminder

Education and automatically extracted skills may be incomplete. Verify numerical parameters, citations, sample and setting fit, methodological assumptions, and ethics requirements before using outputs in real research.
