**研究项目**是教育版的主要工作入口。它保存研究定义、来源与材料、证据提取、方案版本、执行关联、表格分析、主张和报告；这些记录帮助研究者判断结论从何而来，不能替代对原文与方法的独立审查。

## 建立教育研究链条

1. 新建项目及研究，填写研究问题、目的、学段、机构类型、课程或任务、语言文化背景、观察时间和待确定事项。研究定义发生变化时保存新版本并写明原因。
2. 在**来源与材料**中登记文献、问卷、访谈、观察、数据集或其他材料，注明来源性质、引用方式和访问限制。本地可上传 PDF、DOCX、TXT 或 MD 文件版本；保存来源不等于内容已经核验。
3. 在原始文件中定位摘录并记录证据；区分**未核验、来源已核对、内容已核对**。文件有新版本或手工转录尚未复核时，重新对照原文与定位信息。
4. 保存研究方案，说明设计、测量、分析、伦理和局限。研究者审阅后**接受当前版本**；若研究定义或证据后来变化，按页面提示复核并更新方案。
5. 依据已接受方案记录执行、分析与主张，再由已接受且当前可复核的主张创建报告版本。下载 Markdown 报告时保留相应版本与引用清单。

## 交给教育研究智能体

在**执行关联 → 交给教育研究智能体**点**建立教育研究会话**。系统会创建新会话并生成**尚未发送的草稿**，其中包含已接受的当前方案及最多 12 条经过内容核对、带引文的出版物摘录。原始文件、CSV 行和参与者记录不会自动附上。研究问题与方案仍是自由文本，发送前请检查是否含可识别学生信息，并确认引文适合交给所选模型服务商。交接内容是研究者整理的上下文，不能视为模型重新验证了来源。

原有未标记领域的历史会话仍按脑科学会话解释；要使用教育方向，请新建会话。研究方向创建后固定。

## 分析与报告

在**表格数据分析**中，可为已登记的数据集来源上传本地 CSV 版本。先接受当前方案，再保存清洗规则并运行描述性统计。页面只展示列概况和汇总；原始 CSV 保留在本地。结果提供版本和状态复核，但均值、标准差等描述性统计不能单独证明因果关系或显著性。

研究主张应关联对应证据、分析或执行记录，明确它们是支持、反驳还是限定该主张。报告按已接受主张保存不可覆盖的版本；当来源、方案、分析或执行记录发生变化时，检查“需要复核”提示，再决定是否接受新版。

## 可选的旧数据目录与本地论文索引

本地安装中的**插件 → 数据集**目前主要是原 BrainPilot 的脑科学数据。它是可选目录，教育会话不会自动加载。**插件 → 知识库 → 我的知识库 / 上传论文**进入本地论文索引流程；教育会话默认不会调用原有本地脑科学知识检索工具。教育文献可先在研究工作台中登记、核对和引用；目录、技能与知识库的区别见[技能与知识库](./skills-knowledge-base)。

若确实需要旧目录中的数据，下载完成后点**用于新研究**把所选路径加入草稿。检查领域、路径、服务商、模型与预期产物后再发送。创建草稿不会启动模型或分析。访问与下载要求见[研究数据集](./datasets)。

## 会话文件与持久文件

会话文件保存在 `<BP_DATA_DIR>/workspaces/<session-id>/`，可复用的输入保存在 `<BP_DATA_DIR>/data/`，运行时通过 `/data/…` 访问。本地新草稿尚未创建会话时，文件面板也可以展示持久库。通过 `@` 选择文件，避免猜测路径。

打开已下载数据会在文件面板定位对应目录，不会把完整数据复制到每个对话。如果使用远程部署，文件属于服务器的数据目录。

## 核对研究结果

打开**轨迹**，选择一个步骤，再通过文件操作打开相关产物，将记录中的动作与保存的文件对应起来。内部恢复检查点不会计入用户产物数量。

核对文件是否包含预期结果，以及回答中的数值是否与文件一致。步骤有记录、任务完成或结果可下载，都不代表科学结论已经批准。如果文件在轨迹事件之后被移动或删除，应从保留的文件中恢复或重新运行必要步骤；轨迹记录本身不能代替产物。

## 停止与稍后继续

用**停止**中断当前模型和工具工作，等待取消完成后再发送修改后的请求。重新打开对话可查看已保存的历史与文件；重启或升级时保留原 BrainPilot 数据目录。

数据集分类、搜索、筛选、详情和下载范围保存在页面 URL 中，刷新及浏览器前进／后退可以返回原视图。对比选择和临时凭证不属于已保存的分析配置。

## 本地与 Cloud 的区别

本地数据集下载器和知识库准备需要后端文件系统与工具访问。上游托管 Cloud 不包含本仓库教育研究版的改动，并隐藏这些本地管理控件。此源码版研究工作台按本机单用户使用设计，没有账户登录或多用户权限隔离；不要把它直接作为可访问敏感学生资料的共享服务。
