title: 故障排查
description: 排查教育研究版的源码启动、领域选择、模型服务商和 MCP 问题。
---

## 先确认正在使用教育研究版

Education Researcher 从本仓库根目录运行：先执行 `npm ci` 和 `npm run build`，再执行 `npm run bp -- up`。上游全局 npm 包及 `brainpilot.chat` 不包含本分支功能。若会话没有教育研究选项，请确认打开的是这次源码进程显示的本地地址，而非旧进程或上游托管站点。

新会话默认教育研究；未标记领域的历史会话按脑科学保留。领域在创建会话时固定，要切换请新建会话。若模型仍给出脑科学内容，检查请求或引用文件中是否带有脑科学背景，并核对**研究方向**与配置给该方向的 MCP 工具。领域设置不会清除底层模型的预训练知识。

## 上游包的 `brainpilot: command not found`

先确认全局包是否安装：

```bash
npm list -g @brainpilot/app --depth=0
```

如果包已安装但命令找不到，查看 npm 全局安装前缀：

```bash
npm prefix -g
```

macOS/Linux 将该前缀下的 `bin` 子目录加入 `PATH`；Windows 则加入该前缀目录本身。

## Node 版本太低

Education Researcher 源码要求 Node.js 22.13.0 或更高版本：

```bash
node -v
```

如果版本低于 `v22.13.0`，请先升级 Node.js。

## npm 全局安装权限错误

如果全局安装遇到权限错误，建议使用 Node 版本管理器，或配置 npm 用户级 prefix。除非你清楚安全影响，否则不要直接用 `sudo` 跑 npm。

## 端口被占用

教育版源码尝试换一个端口：

```bash
npm run bp -- up --port 9010
```

上游全局包对应命令：

```bash
brainpilot up --port 9010
```

如果之前用后台模式启动过：

```bash
brainpilot status
brainpilot down
```

## 启动成功但浏览器打不开

先确认打开的是终端打印的 URL，然后查看日志：

```bash
brainpilot logs
```

如果 BrainPilot 跑在远程机器或容器里，确认端口已经暴露，并且你的浏览器能访问到。

## Provider 测试失败

逐项检查：

- API key 是否有效，复制时是否带了多余空格
- Base URL 是否符合服务商要求
- 协议是否与服务商匹配
- 模型 ID 是否存在，例如 `glm-5.2`
- 当前机器是否能访问服务商网络

修改当前服务商后，如果已有会话仍在使用旧设置，请新建会话。

## MCP 服务器没有显示工具

逐项检查：

- 服务器名称是否唯一且清晰
- 传输方式是否匹配：`stdio`、`http` 或 `sse`
- HTTP/SSE URL 是否可访问
- 鉴权 headers 或 query token 是否正确
- stdio 命令路径和参数是否有效
- 服务器的**用于研究方向**是否包含当前会话；新服务器默认教育研究，旧配置未标记时仅供脑科学使用

修改 MCP 设置后，新建一个会话。

## 干净的无 Key 冒烟测试

用 mock 模式把安装问题和 provider 问题分开；下面是上游全局包命令，教育版源码请使用 `BP_MOCK=1 npm run bp -- up --dir ./bp-smoke-test --port 9011`（PowerShell 先设置 `$env:BP_MOCK = '1'`）。mock 不能评价模型的教育研究能力。

```bash
BP_MOCK=1 brainpilot up --dir ./bp-smoke-test --port 9011
```

如果 mock 模式可以正常启动，重点排查 provider 或 MCP 配置。

## 数据集下载失败

按[研究数据集](./datasets)指南检查所选范围的下载工具、访问要求和重试步骤。工具应安装在后端所在机器。HTTP 中断后保留 `.part` 文件；校验失败的文件会另存为唯一的 `.corrupt-…` 副本，让下次重试获取新文件。保留大体积排错副本时注意剩余磁盘空间。

如果已完成的数据集缺少文件，重新打开详情并运行相同范围。已有 HTTP 文件会复用，有校验值时会重新检查，缺失文件可以补下载；提供方命令型下载遵循其工具自身行为。

## 本地知识库尚不可用

PDF 上传和建立搜索索引是不同步骤。查看**设置 → 知识库**中是否缺少环境／模型准备、OCR 或元数据凭证，以及是否有索引阶段失败。高级日志提供具体错误；暂停日志跟随不会停止构建。详见[技能与知识库](./skills-knowledge-base)。
