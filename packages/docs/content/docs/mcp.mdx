Education Researcher can connect agents to tools exposed through the Model Context Protocol. Configured tools have names such as `mcp__server_name__tool_name`. Education uses include literature search, authorized institutional documents, and methods tools. Check each service's data access, citation locators, and permissions; verify model-produced citations against original texts.

## Add a Server in the UI

1. Start BrainPilot.
2. Open **Settings -> MCP**.
3. Click **Add Server**.
4. Choose a transport: `stdio`, `http`, or `sse`.
5. Fill in the transport-specific fields.
6. Under **Research focus**, choose **Education research**, **Neuroscience**, or **Education and neuroscience**. New servers default to education; existing unmarked configurations remain available only to neuroscience sessions.
7. Save the server and start a new session so the tool list is refreshed.

## HTTP Server Example

| Field | Value |
| --- | --- |
| Name | `paper_search` |
| Transport | `http` |
| URL | `https://your-mcp.example.com/mcp` |
| Research focus | `Education research` |

If the MCP endpoint needs authentication, use the headers field when available or follow the server provider's instructions.

## stdio Server Example

Local MCP servers can be launched as child processes:

```json
{
  "mcpServers": {
    "filesystem": {
      "type": "stdio",
      "command": "npx",
      "args": [
        "-y",
        "@modelcontextprotocol/server-filesystem",
        "/path/to/allowed/folder"
      ],
      "env": {},
      "researchDomains": ["education"]
    }
  }
}
```

Use a narrow folder path for filesystem tools. Avoid granting access to your whole home directory.

## Config File Format

BrainPilot writes MCP config under the data directory:

```text
brainpilot/bp_template/mcp_servers.json
```

The file follows the common `mcpServers` map:

```json
{
  "mcpServers": {
    "web_search": {
      "type": "http",
      "url": "https://your-mcp.example.com/mcp",
      "researchDomains": ["education"],
      "headers": {
        "Authorization": "Bearer <token>"
      }
    },
    "events": {
      "type": "sse",
      "url": "https://your-mcp.example.com/sse",
      "researchDomains": ["education", "neuroscience"]
    }
  }
}
```

## Safety Notes

- Treat MCP servers like code or services you trust; agents can call their tools.
- Do not commit API keys in MCP URLs or headers.
- Prefer descriptive server names because they become part of the agent-facing tool namespace.
- Research focus controls which sessions can see a server; it does not verify the quality of returned literature or how an external service handles data.
- Restart or create a fresh session after changing MCP servers.
