## 克隆并构建

本仓库的教育研究改动仅在 Education Researcher 源码中。请使用 Node.js 22.13.0 或更新版本：

```bash
git clone https://github.com/Kirihara-Ryouji/Education-Researcher.git
cd Education-Researcher
npm ci
npm run build
```

## 从源码启动

```bash
npm run bp -- up
```

无 Key 界面冒烟测试（不用于评价模型的教育研究质量）：

```bash
BP_MOCK=1 npm run bp -- up
```

通过 `npm run` 使用 CLI 时，请保留 `--` 分隔符，确保参数能正确透传。

## 常用检查

开 PR 前建议运行：

```bash
npm run typecheck
BP_MOCK=1 npm test
npm test -w @brainpilot/web
npm run build -w @brainpilot/web
```

构建文档：

```bash
npm run docs:build
npm run docs:check
```

## 包结构

| Package | 作用 |
| --- | --- |
| `@brainpilot/protocol` | 共享的 wire 和 domain schema |
| `@brainpilot/runtime` | 智能体编排、会话状态、MCP bridge、运行时服务 |
| `@brainpilot/backend-core` | REST 与 SSE 后端核心 |
| `@brainpilot/web` | 浏览器 UI |
| `@brainpilot/app` | npm CLI 包：`brainpilot` / `bnpt` |
| `@brainpilot/skills` | 内置技能内容包 |
| `@brainpilot/client-cli` | 无头验证客户端 |
| `@brainpilot/docs` | 静态公开文档站点 |

包名和 CLI 命令仍保留 BrainPilot 上游命名；文档与默认研究工作流以本分支的教育研究功能为准。原上游仓库位于 [NeuroAIHub/BrainPilot](https://github.com/NeuroAIHub/BrainPilot)，已发布 npm 包不包含本分支改动。

## 文档工作流

文档内容位于：

```text
packages/docs/content/docs/
```

英文页面使用 `page-name.mdx`，简体中文页面使用 `page-name.zh-cn.mdx`。

不要把真实 provider key、MCP token 或内部专用端点写进公开文档。文档 CI 会做基础密钥扫描，但 reviewer 仍然需要人工检查示例。

## Pull Request

纯文档改动可以直接开 PR。新功能或架构改动建议先开 issue 或 discussion，再进入实现。

## 数据集检查与文档一致性

```bash
BP_MOCK=1 npm test -- packages/backend-core/test/datasets.test.ts packages/backend-core/test/datasetJobs.test.ts
npm test -w @brainpilot/web -- src/__tests__/datasetMarketplace.test.ts src/__tests__/datasetFeedback.test.ts
```

后端测试包含本地 HTTP 恢复用例，不需要下载大型公开数据。单独的 `npm run test:datasets` 会下载公开文件，运行前查看脚本并核对磁盘与网络预算。

中英文页面与两份 `meta*.json` 导航应保持一致。原版 BrainPilot Cloud 按上游提交同步自己的文档，**不会**因本仓库文档构建成功而变成教育研究版。发布本分支文档时，应单独核对站点构建与在线路由。
