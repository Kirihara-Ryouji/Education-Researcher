Education Researcher 内置六项教育研究方法技能：**证据综述、研究设计、测量、质性研究、学习分析与隐私、教育 AI 评价**。它们是可按需读取的方法文档，不是训练后的新模型，也不是论文全文库。原 BrainPilot 的脑科学技能仍保留给主动选择的脑科学会话；教育会话默认只发现教育技能及允许的通用技能。

教育技能目录的[权威来源索引](https://github.com/Kirihara-Ryouji/Education-Researcher/blob/main/packages/skills/skills/22_Education/AUTHORITATIVE_SOURCES.md)列出可核对的方法、报告和伦理入口。它是**入口清单**，不包含自动下载的教育论文全文；引用具体研究结果前仍须核对原文。

## 内置技能

技能在仓库中的位置：

```text
packages/skills/skills/
```

运行时会被物化到数据目录：

```text
brainpilot/bp_template/skills/
```

脚手架不会覆盖用户已经编辑过的技能文件。

## 一个技能包含什么

每个技能都有一个 `SKILL.md`，并带有必需的 frontmatter：

```yaml
---
name: "skill-name"
description: "用于匹配的一句话摘要，应该包含清晰关键词。"
domain: "education-research"
version: "1.0.0"
---
```

`description` 会帮助智能体判断何时应该使用该技能。请写得清楚、具体、可检索。

## 新增技能

贡献内置技能时：

1. 在 `packages/skills/skills/` 下选择已有分类，或新增分类。
2. 创建 `<category>/<skill-name>/SKILL.md`。
3. 较长的参考表、示例或原始资料放到 `references/`。
4. 提交 PR 前运行技能包构建：

```bash
npm run build -w @brainpilot/skills
```

## 扩充教育研究技能

可以以[六项内置教育技能](https://github.com/Kirihara-Ryouji/Education-Researcher/tree/main/packages/skills/skills/22_Education)为模板，将已核实的方法和适用边界写入自己的技能。来源、适用学段、测量前提、伦理限制和版本日期应清晰标注。

- **`paper-to-skill`** 可从论文、PDF 或文本生成方法技能的初稿；研究者要核对原文、参数、引文和授权范围。
- **`repo-to-skill`** 可把可信代码库转换成结构化方法技能；检查代码与文档版本是否一致。
- 自己编辑的技能放在 `<data-dir>/bp_template/skills/<category>/<skill-name>/SKILL.md`，新建会话后检查它是否实际可见。教育会话的内置资源过滤不会把任意脑科学技能自动纳入教育方向。

上游的 [`awesome_cognitive_and_neuroscience_skills`](https://github.com/NeuroAIHub/awesome_cognitive_and_neuroscience_skills) 和 [`nature-skills`](https://github.com/Yuan1z0825/nature-skills) 是原项目可选资料，不代表教育研究资源，也不会自动成为教育会话的依据。

## 原有本地论文知识库

下面的上传与索引流程沿用原 BrainPilot 本地知识库。**教育会话默认不调用这套本地脑科学知识检索工具**。要在教育研究中管理、核验并引用文献，优先使用[研究工作区](./research-workspace)的来源与证据记录；若需自动检索自己的教育论文库，应另行接入经审查且配置为教育方向的检索服务。

本地安装中打开**设置 → 知识库**，或从**插件 → 知识库 → 我的知识库 / 上传论文**进入。

1. 点**选择 PDF**上传论文。单个文件必须是有效、非空的 PDF，不能超过 256 MB。同名文件会被拒绝；若要同时保留两个版本，请先重命名。
2. 点**开始准备**安装本地搜索环境及嵌入、重排序模型。界面预计下载约 2.5 GB，需要至少 3 GB 可用空间；耗时取决于网络和机器。
3. 在**高级与故障排查**配置 OCR 和元数据抽取，再开始建立索引。这些阶段可能将文档内容发送到所选外部服务，嵌入与重排序在本机运行。
4. 等待知识库显示可搜索。后续添加论文可再次建立索引；上传完成不等于论文已被索引。

高级区域提供准备／构建阶段和日志。向上滚动可暂停跟随并查看较早的输出，点**回到最新日志**恢复跟随；滚动日志不会取消构建。失败后修正配置，可重试对应步骤。

npm 安装会把随包提供的流水线准备到 `~/.brainpilot/KnowledgeBase/`，`BP_KB_ROOT` 可以覆盖该位置。源码和容器部署请查看高级面板检测到的路径。如果知识库与 BrainPilot 数据目录分开，应分别备份。后端和运行时如何共享路径，见 [Docker 部署](./docker)。

托管 Cloud 不提供本地管理界面，预置检索能力由服务端控制。

## 接入教育文献检索服务

开源包没有预装可直接检索的教育论文全文库。你可以通过 MCP 接入自己的教育文献检索服务，并在服务器设置中选择**教育研究**方向：

- 经机构授权的教育论文或政策文档库
- 可返回稳定来源定位与访问日期的论文搜索服务
- 仅暴露已获授权目录的文件或数据库检索工具
- 内部文献综述 API

服务返回的摘要、摘录与引文仍需核对原文。[MCP 工具](./mcp)说明服务器的研究方向设置与数据访问边界。

## 使用前验证

教育技能和自动提取的技能都可能不完整。用于真实研究前，请核对数值参数、引用、样本与情境适配、方法假设及伦理要求。
