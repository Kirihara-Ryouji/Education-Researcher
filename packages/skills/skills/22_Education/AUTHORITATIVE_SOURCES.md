# 教育研究权威来源索引

核验日期：2026-09-27。以下是可供**在线核对**的方法与资源入口，并非已下载到本地的全文或可任意再分发的材料。使用时打开原始页面，核对版本、适用范围及最新政策；对具体研究结论仍需查阅原始论文和数据。

| 来源 | 适用范围与使用边界 |
| --- | --- |
| [ERIC 教育文献数据库](https://eric.ed.gov/)（[美国教育科学研究所介绍页](https://ies.ed.gov/use-work/education-research-database-eric)） | 检索教育研究的书目信息、主题词和可用全文。索引记录本身不证明研究可信；逐篇核对出版信息、研究设计与原文。直接打开 ERIC 站点时如遇连接超时，可先通过 IES 介绍页进入。 |
| [What Works Clearinghouse 手册](https://ies.ed.gov/ncee/wwc/handbooks)（美国教育科学研究所，页面列示现行 Version 5.0） | 用于判断教育干预研究的设计质量和 WWC 证据评级。评级需结合对应 review protocol 和原研究；不能把本技能的快速审阅称为正式 WWC 认证。 |
| [WWC 研究作者报告指南](https://ies.ed.gov/ncee/wwc/document/235) | 随机和准实验组设计的报告信息。该指南本身不规定 WWC 设计评级；核验时页面标注 4.1 版下载文件不可用，可查看页面内容或可用的旧版，并以现行手册核对标准。 |
| [AERA 实证社会科学研究报告标准](https://www.aera.net/Publications/Standards-for-Research-Conduct) | 教育研究报告的透明度、方法与证据呈现；是报告指导，不代替伦理审查或因果识别。 |
| [《教育与心理测验标准》项目网站](https://www.testingstandards.net/)（AERA、APA、NCME，2014 版） | 教育测量的效度、信度与公平性判断。网页说明现有版本和修订状态；不要摘录或复制受版权保护的章节到本项目。 |
| [PRISMA 2020 核对表](https://www.prisma-statement.org/prisma-2020-checklist) | 系统综述的**报告**透明度；不保证检索全面或纳入研究质量，也不适用于把普通叙述综述伪装成系统综述。 |
| [SRQR 定性研究报告标准](https://www.equator-network.org/reporting-guidelines/srqr/)（原始报告指南的索引） | 访谈、观察等定性研究的报告完整性。源自医学教育及其他定性领域，应用到课堂时需说明情境。 |
| [美国教育部学生隐私与教育技术资源](https://studentprivacy.ed.gov/privacy-and-education-technology) | 美国学校使用教育技术的隐私实践入口；对其他司法辖区不构成法律意见。 |
| [美国教育部 FERPA 研究例外说明](https://studentprivacy.ed.gov/faq/may-educational-agency-or-institution-disclose-personally-identifiable-information-students) | 说明美国 FERPA 在特定条件下的研究数据披露例外及书面协议要求。是否适用须由机构及合格法律/隐私人员判断；不能推定研究人员自动获得数据使用权。 |
| [NIST 隐私框架](https://www.nist.gov/privacy-framework) | 自愿性的隐私风险管理框架，非法律或机构许可替代品。核验时页面同时列出 1.0 版和 1.1 初步公开草案，引用时写明实际采用的版本。 |
| [UNESCO《生成式 AI 在教育和研究中的指南》](https://www.unesco.org/en/articles/guidance-generative-ai-education-and-research)（2023 年发布，页面 2026 年更新） | 评估教育场景中的人类监督、适龄性、数据与公平风险；是政策指导，具体实施须适应本地制度。 |
| [NIST AI 风险管理框架](https://www.nist.gov/itl/ai-risk-management-framework) | 自愿性、跨行业 AI 风险管理框架。页面注明 AI RMF 1.0 正在修订；评估时核对实际使用版本。 |
